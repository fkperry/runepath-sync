# Welcome to RunePath Sync! 🧭

**Welcome, adventurer!** RunePath Sync is an open-source companion plugin for Old School RuneScape players who want to track skills, quests, achievement diaries, and combat achievements in RunePath without repeatedly exporting JSON files.

We are building this in public. Thanks for visiting, and feel free to follow development or report issues. The goal is a clean, secure, opt-in connection between RuneLite and the RunePath progress tracker.

## Current development status

**The plugin is a work in progress and is not yet released on RuneLite's Plugin Hub.** **RunePath is now live at [runepath.floot.app](https://runepath.floot.app).** The RuneLite plugin builds in the cloud, but real gameplay and pairing still need testing after RuneLite maintenance.

- [View the RunePath Sync implementation and full README](https://github.com/fkperry/runepath-sync/tree/feature/runepath-sync-mvp)
- [Review the current development pull request](https://github.com/fkperry/runepath-sync/pull/1)
- [See automated Java build results](https://github.com/fkperry/runepath-sync/actions)

This `master` branch is intentionally still the official RuneLite example-plugin template until testing and review are complete. The new Java code lives on the development branch.

## Privacy comes first

Sync is disabled until the player opts in. No Jagex login details or bank contents are collected. Each connection is approved through RunePath and can be revoked.
